# CLIP! 1.0.0

<img src="images/long_logo.png" alt="CLIP-LOGO" width="760">

**Protein–ligand interaction analysis and visualization in UCSF ChimeraX.**

CLIP! combines ChimeraX and PLIP in a plugin for analyzing molecular complexes,
exploring their interactions, and preparing figures through a graphical interface.
Analysis uses the PLIP engine, while visualization uses native ChimeraX models,
labels, and rendering.

## Getting started

1. Download and extract `CLIP-1.0.0.zip`.
2. Follow the [installation guide](INSTALLATION.md) to install the plugin and
   configure its analysis environment.
3. In ChimeraX, open **Tools → Structure Analysis → CLIP!**.
4. Choose your language, open a protein–ligand complex, and click **Analyze structure**.
5. Explore the results, customize the scene, and export your figure.

If you already have a compatible XML report and its matching structure, you can
use CLIP! to visualize the results without installing the analysis engine.

## Features

- Explore eight interaction types and filter their display by ligand and category.
- Select residues from the results table and focus on the binding site.
- Adjust backgrounds, lighting, materials, colors, representations, and transparency.
- Display residues and distances as 3D labels and position them manually.
- Save and share visual styles as JSON files.
- Export PNG, TIFF, or JPEG figures, with transparent backgrounds supported in PNG and TIFF.
- Export interactions as CSV and save the scene as a ChimeraX `.cxs` session.

## Languages

English · Español · Deutsch · Français · 中文（简体） · 日本語 · Português

The language selector at the top of the panel switches the interface language and
remembers your preference. Simplified Chinese and Brazilian Portuguese are included.
Switching languages preserves results, filters, styles, and manually positioned labels.

## Compatibility

CLIP! 1.0.0 is an experimental integration validated with **ChimeraX 1.12 on macOS**,
PLIP 3.0.1, and Open Babel 3.2.1. Instructions for Windows and Linux are included;
operation on those platforms still requires validation.

The plugin is installed from a `.whl` file. Calculating new interactions requires
an external Python environment with the analysis dependencies; the ZIP includes
a setup script for creating it with Conda/Miniforge. PyMOL is not required.

Results represent a snapshot of the analyzed coordinates. Review the
[limitations](DOCUMENTATION.md#alcance-y-limitaciones) before working with
trajectories, large structures, or advanced analysis modes.
